# data/

- `exact_33.csv` — 161 proven-exact values of z(m,n;3,3) (m=3..16). Copied from
  `zarankiewicz_generalized/gpt_agent/data/exact_table.csv`, which was extracted
  from Tan 2022 (arXiv:2203.02283, Table 3, bold entries) and cross-checked.
  Used as an *external, cited* fact table for the inclusion argument
  (Guy's Argument I). Every use is recorded in the assumptions ledger of a run.
- `open_33.csv` — cells with a gap between best known lower bound and best
  proven upper bound (generated by `python -m zar_ub open`).
