## Definitions

- Column-side budget: in a K_{3,3}-free m×n matrix, every 3-subset of rows is
  contained in ≤ 2 column supports, so Σ_j C(c_j,3) ≤ 2·C(m,3).
- WF(m,n) = min over both orientations of the exact integer maximum of Σc_j
  subject to the convex budget (marginal cost of raising a column c→c+1 is
  C(c,2), so level-filling is optimal; heights capped at m).
- d(m,n) = WF(m,n) − z(m,n): the "structure deficit" — how much of the truth
  pure counting misses.

## Findings [VERIFIED-NUMERICALLY on all 161 cells]

1. d ≥ 0 everywhere (sanity: WF is a genuine upper bound; no violations).
2. **78/161 cells have d = 0** — the exact value is fully explained by counting.
3. All 41 Culík-regime cells (n ≥ 2·C(m,3); happens for m=3 all n, m=4 n≥8,
   m=5 n≥20) satisfy z = 2n + 2·C(m,3) = WF. Culík's theorem confirmed
   numerically on every applicable cell.
4. Rows m=3,4,5 are counting-tight at EVERY n in the table — including cells
   below the Culík threshold (e.g. (4,4)=13, (5,5)=20). First deficit: m=6.
5. Deficit spectrum: d=1 (28 cells), d=2 (24), d=3 (15), d=4 (10), d=5 (5),
   d=8 (1: the corner (16,16), z=128=16·8, WF=136).
6. Odd fingerprints to explain:
   - m=6 row: d=1 exactly at n ∈ {7,8,10}; d=0 at n=6, 9, and ≥11.
   - d=5 cells: (11,17),(12,16),(13,16),(14,16),(15,16) — the exactness
     frontier of the published table (rows m=12..15 end at n=16).
   - (16,16): d=8, z=16·8 (every row degree 8) — looks like a very regular
     extremal structure; find it (design? unital-like? Denniston?).

## Formula hypothesis (CONJECTURE, forming)

z(m,n;3,3) = WF(m,n) − d(m,n) with d generated by a small local-constraint
correction. Candidate mechanism the global budget ignores:

- Pair-local budget: fix rows pair P; columns containing P with degrees c_j
  give Σ_{j ⊇ P} (c_j − 2) ≤ 2(m−2)  (each triple P∪{r} covered ≤ 2×).
- Row-local budget: fix row r; Σ_{j ∋ r} C(c_j−1, 2) ≤ 2·C(m−1, 2).

Next: implement the degree-profile LP/IP with local budgets (level-1/level-2
hierarchy) and test how much of the deficit spectrum it reproduces. If the
level-2 bound minus rare corrections reproduces all 161 cells, we have a
full-table formula with an interpretable mechanism.
